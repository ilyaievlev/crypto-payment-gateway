Реализации отдельных сетей находятся в `crypto_engine/<network>`.

Сейчас для TRON реализованы:

- деривация адресов BIP-44 по пути `m/44'/195'/0'/0/index`;
- проверка TRON-адресов в формате Base58Check;
- построение неподписанных переводов TRX и TRC-20;
- локальная подпись транзакций secp256k1;
- строгая проверка содержимого транзакции перед подписью.

Движок получает байты сида только через `domain.SeedProvider.WithSeed`. Провайдер
отвечает за зашифрованное хранение, расшифровку и очистку переданного сида после
возврата из callback. Движки очищают производный приватный материал самостоятельно.

Генерация и зашифрованное хранение сидов находятся за пределами этого пакета.
Секреты нельзя помещать в protobuf-контракты, ошибки, логи или трассировки.
